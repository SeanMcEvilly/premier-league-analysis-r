# Premier League 2020/21 – Data Analysis Using R

## Project Overview

This project explores the 2020/21 English Premier League season using R to analyse match results, goals, shooting statistics and other match-related variables.

The aim was to apply data analytics techniques to football data, identify patterns in match performance, and communicate findings through data visualisations.

## Project Objectives

- Analyse home wins, draws and away wins.
- Explore goal-scoring patterns across Premier League matches.
- Investigate home advantage and home versus away performance.
- Examine shooting statistics, including shots and shots on target.
- Create visualisations to communicate insights from the data.

## Dataset

The dataset contains 380 matches from the 2020/21 Premier League season and includes 16 variables relating to match outcomes and performance statistics.

## Tools and Technologies

- **R** – Data analysis and statistical calculations
- **dplyr** – Data manipulation and summarisation
- **ggplot2** – Data visualisation

## Methodology

1. Explored the dataset structure, variables and match statistics.
2. Analysed match outcomes and performance statistics.
3. Created charts to visualise match results and identify patterns.
4. Interpreted the results to communicate insights from the season.

## Key Findings

The 380 matches produced the following distribution of results:

- **Home wins:** 144 (37.9%)
- **Draws:** 83 (21.8%)
- **Away wins:** 153 (40.3%)

Away wins were slightly more common than home wins during the 2020/21 season.
