# premier-league-analysis-r
Exploratory data analysis of the 2020/21 English Premier League season using R and ggplot2.
Project Overview

This project explores the 2020/21 English Premier League season using R. The analysis examines match outcomes, home advantage, goals scored and shooting statistics to identify patterns across 380 matches.

Objectives

Analyse home wins, draws and away wins.

Compare home and away scoring patterns.

Explore the relationship between shots on target and goals scored.

Investigate differences in team shooting statistics.

Communicate findings through data visualisations.

Tools Used

R

dplyr

ggplot2

Methodology

Import and inspect the match dataset.

Clean and summarise relevant variables.

Calculate descriptive statistics and match-result percentages.

Create charts to investigate trends and relationships.

Interpret the results and identify key findings.

Key Findings

Match results: 144 home wins, 83 draws and 153 away wins.

Home wins represented approximately 38% of matches.

Away wins represented approximately 40% of matches.

Draws represented approximately 22% of matches.
